#  AI-Based URL Phishing Detector

##  Description
AI-Based URL Phishing Detector is a Python-based Machine Learning project that detects whether a URL is Safe or Phishing. The system analyzes URL features such as URL length, HTTPS usage, suspicious keywords, and special characters to identify malicious links.

##  Features
- Machine Learning based detection
- Terminal-based interface
- Fast and lightweight
- Real-world cybersecurity application

##  Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
